# 大肥鱼表情包记账

> `astrbot_plugin_dafeiyu_memelog` · v0.1.1 · [大肥鱼](https://github.com/mengbaiyoudianxian/dafeiyu) 的自写插件之一

表情包是按概率发的；没真发出去的那张，不留在聊天记录里，免得她以为自己发过图、说起没发过的图

## 安装

AstrBot（4.x）后台 → 插件 → 右上角「+」→ 从链接安装，填：

```
https://github.com/mengbaiyoudianxian/astrbot_plugin_dafeiyu_memelog
```

装完在插件列表里点开它的配置，按需改。平台目前只适配 aiocqhttp（NapCat / OneBot v11）。

## 怎么用

装上就行，不用设置
